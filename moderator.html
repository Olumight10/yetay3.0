Session Scheduling

Set Demo & CBT Timing

Submitting a window records the current time as the reference. The session opens after Start (min) and closes after End (min) from that reference.

Demo Session

demo_time · church_login.DEMO_SUBMITTED

Submitting records "now" as the reference timestamp.

Overwrites DEMO_SUBMITTED for every church in church_login.

CBT Session

cbt_time · church_login.CBT_SUBMITTED

Submitting records "now" as the reference timestamp.

Overwrites CBT_SUBMITTED for every church in church_login.

Churches viewing the CBT dashboard count down to Start minutes from the moment you submit a timing, then the session stays open until End minutes from that same moment. The bulk triggers are independent — use them to reset submission flags before opening a new session, or to lock everyone out after grading.
